# Recall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "Food recall" tampil sebagai **Recall**, dengan jenis catatan Bangun tidur dan Istirahat dan jam 00.00–23.00.

**Architecture:**
- Model catatan recall dilepas dari kuis v1. `src/lib/food-recall.ts` memiliki jenis, jam, dan skemanya sendiri, sehingga `ACTIVITY_KINDS` dan `activityEntrySchema` kuis v1 tidak berubah.
- Dua isian catatan, `ActivityList` (tablet pasien) dan `ActivityListFields` (panel staf), hanya dipakai recall. Keduanya beralih ke model baru.
- Nama tampil diganti di setiap string yang terlihat. Identifier, rute, berkas, dan basis data tetap. Tanpa migrasi.

**Tech Stack:** Next.js 15, zod, MUI (panel admin), Tailwind (halaman pasien), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-23-recall-design.md`

## Global Constraints

- Jenis (urutan tampil): `MAKAN_MINUM` "Makan/minum", `KAPSUL_OBAT` "Kapsul/obat", `OLAHRAGA` "Olahraga", `BANGUN_TIDUR` "Bangun tidur", `ISTIRAHAT` "Istirahat".
- Jam: bilangan bulat 0–23. Label lewat `minutesToTimeLabel(hour * 60)`, jadi "00.00" sampai "23.00".
- Isi catatan wajib (setelah trim) untuk semua jenis kecuali `BANGUN_TIDUR`. Batas 200 karakter (`TEXT_LIMITS.activity`).
- Format satu baris: tanpa isi `"05.00 Bangun tidur"`, dengan isi `"13.00 Istirahat — tidur siang 1 jam"`.
- Ganti nama: di setiap string yang terlihat pengguna, "Food recall" → "Recall" dan "food recall" → "recall". Contoh pasti:
  - "Food recall & BIA hari ini" → "Recall & BIA hari ini"
  - "Tawarkan food recall" → "Tawarkan recall"
  - "food recall ✓" → "recall ✓"
  - "Food recall: sudah diisi" → "Recall: sudah diisi"
  - "Food recall H-1 (…)" → "Recall H-1 (…)"
  - "Isi food recall" → "Isi recall"
  - "Simpan food recall" → "Simpan recall"
  - "Food recall disimpan." → "Recall disimpan."
  - "Food recall disalin ke S." → "Recall disalin ke S."
  - "Food recall Anda sudah diterima dokter." → "Recall Anda sudah diterima dokter."
  - Judul bagian, tab, kolom, dan aksi "Food recall" → "Recall"

  Komentar, nama fungsi/tipe/berkas, rute `/food-recall`, kunci audit, dan kolom basis data tidak diubah.
- Pesan WA, baris pertama: `Halo ${nama depan}, ini ${CLINIC_NAME}. Mohon catat apa saja yang Anda makan, minum, dan lakukan kemarin, termasuk jam bangun dan istirahat, sebelum konsultasi (±3 menit): ${link}`
- Halaman tablet pasien:
  - Teks bantu: "Tambahkan satu per satu: jam, jenisnya, lalu isinya, termasuk jam bangun tidur dan istirahat. Tulis yang benar-benar terjadi kemarin."
  - Judul tab browser: "Recall Kemarin".
- Tombol hapus baris: `aria-label` = `Hapus ${entry.text || label jenis}`.

## Review Focus

1. **Catatan lama** (jenis kuis v1, jam 06–22, sudah tersimpan) tetap tampil dan tetap lolos simpanan staf (Lengkapi). Tidak boleh muncul "Catatan tidak sah". Tes: Task 1.
2. **Pasien hanya mengirim "05.00 Bangun tidur" tanpa isi** → diterima dan tersimpan. Tes: Task 1 (integrasi).
3. **Isi berupa spasi saja:** ditolak untuk Makan/minum, tetapi tersimpan kosong untuk Bangun tidur. Tes: Task 1.
4. **Salin ke S** untuk baris Bangun tidur tidak menyisakan " — " di ujung baris. Tes: Task 1.
5. **Jam 00.00** diperlakukan sebagai jam sungguhan, bukan "kosong": terurut paling atas dan tampil di tabel. Tes: Task 1.
